# Market Place - Aplicación React Native

Este es un proyecto de React Native para una aplicación de marketplace.

## 📱 Requisitos Previos

- Node.js >= 20
- npm o yarn
- Android Studio (para desarrollo Android)
- Xcode (para desarrollo iOS en macOS)
- Watchman (recomendado)

## 🚀 Instalación

1. Clonar el repositorio:
```bash
git clone https://github.com/saasha10/market-place.git
cd market-place
```

2. Instalar dependencias:
```bash
npm install
```

3. Para iOS, instalar los pods (solo macOS):
```bash
cd ios
pod install
cd ..
```

## 📱 Ejecutar la Aplicación

### Android
```bash
npm run android
```

### iOS
```bash
npm run ios
```

### Iniciar Metro Bundler
```bash
npm start
```

## 🧪 Tests

Ejecutar tests:
```bash
npm test
```

## 📝 Scripts Disponibles

- `npm start` - Inicia Metro Bundler
- `npm run android` - Ejecuta la app en Android
- `npm run ios` - Ejecuta la app en iOS
- `npm run lint` - Ejecuta ESLint
- `npm test` - Ejecuta los tests con Jest

## 🛠️ Stack Tecnológico

- React Native 0.83.1
- React 19.2.0
- TypeScript 5.8.3
- Jest para testing
- ESLint para linting
